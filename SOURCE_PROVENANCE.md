# Source provenance and release scope

Prepared from the locally inspected Polymarket recorder/model source at base
commit `4a1d245fbed7c48aff589b380aae9007bbe7823c`. Runtime Python and SQL were
preserved; documentation, configuration, dependency locks and test support were
prepared for a source-only release.

The candidate uses new local history, not a clone or rewrite of the old Git
repository. Original refs, reflogs, objects, models, databases, training exports,
strategy grids and experiment results are excluded. The original remains intact.
The local snapshot identity records preparation; it does not claim authorship
or transfer copyright. The owner subsequently approved Apache-2.0 for this
open-source edition; the grant is in LICENSE, with attribution in NOTICE.

The owner approved holding back current weights and private datasets. The only
sample data here is explicitly generated fictional JSON; the generator reads no
private files. Local generated training/model outputs are ignored. A future demo
checkpoint requires separate review and is not implied by this preparation.

The owner confirms the inspected Mac checkout is the latest authoritative copy
and approves it as the source base. No registered Ubuntu checkout was available
for comparison, so historical deployment parity was not independently measured.
Source authority and the Apache-2.0 decision are now resolved by owner instruction.
